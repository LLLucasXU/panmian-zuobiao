# 盘面坐标

同花顺 AI 产品笔试题 2 的可操作 Web 原型。用户选择 A 股指数和观察窗口，先检查取数计划，再生成带来源、时点、口径和原始字段的市场状态卡，并可继续追问。页面只使用真实接口数据；接口失败会显示缺失，不生成替代数值。

## 本地启动

需要 Node.js 22.13+。

```bash
npm install
cp .env.example .env.local
# 在 .env.local 中填入自己的服务端密钥
npm run dev
```

浏览器打开本地开发地址。运行 `npx tsc --noEmit` 和 `npm run build` 检查类型与构建。部署使用 Sites 的 Vinext/Cloudflare Workers 运行时，配置文件在 `.openai/hosting.json`，密钥在站点环境变量中设置。

| 环境变量 | 用途 |
| --- | --- |
| `FUYAO_API_KEY` | 扶摇 REST 真实行情、成分股、估值、交易日历和涨跌停池，必填 |
| `IFIND_API_KEY` | iFinD MCP 新闻片段检索，缺失时事件维度标记不可用 |
| `IFIND_EVENT_SNAPSHOT_JSON` | 可选：Worker 无法连接 iFinD 的非标准端口时，使用不超过 7 天的真实检索快照并醒目标注 |
| `OPENAI_API_KEY`、`OPENAI_MODEL` | 可选的受约束文字归纳；缺失时保留确定性报告并明确标注 |

密钥只保存在本机 `.env.local` 或托管平台的 Secret 环境变量中；不得提交到仓库。公开 URL 会消耗上述账号的免费额度，建议设置用量告警。

## 用户和设计

目标用户是想快速理解 A 股市场状态、且需要检查依据的投研用户。产品先给出系统准备查询的七个维度，再展示“事实—归纳—不确定与边界—切换条件”。证据抽屉允许从每条说法追到指标、样本数、计算式、原始字段、来源端点或资讯原文。视觉采用暖纸色背景、克制的珊瑚色交互和深色证据面板；只借鉴公开设计规范的编辑式结构，不使用 Claude 品牌资产。

## AI 的角色与限制

iFinD MCP 根据自然语言查询检索相关资讯。可选的大模型只对已核验的结构化证据做文字归纳，服务端校验引用 ID、数字和禁用交易建议；校验未通过即保留程序生成的报告。核心指标、状态阈值、覆盖率和置信度由程序计算。缺少模型密钥时页面显示“确定性模板”，不声称模型已生成解释。

状态规则为**原型阈值，未经历史回测验证**：目标指数近 20 个交易日变化超过 ±2% 判方向；最近交易日有效上涨样本占比 ≥55% 或 ≤45% 判参与度；全市场快照有效覆盖率低于 95% 不判完整市场状态。置信度指证据完备度，不是涨跌概率。页面不提供确定性预测、收益承诺、仓位或买卖建议。

## 数据和口径

- **扶摇金融数据 API**：交易日历、指数日 K、全 A 股分页快照、沪深 300 成分股正 PE-TTM 中位数、指数成交额历史比较、涨跌停/炸板池。最近已收盘交易日由交易日历和上海时间确定。全市场快照按代码去重并报告有效覆盖率。PE 仅描述沪深 300 正值样本，不等于市场估值分位。
- **iFinD MCP**：`search_news` 检索带日期和 URL 的相关资讯片段。资讯仅作为待核对线索，不能证明政策效果或市场因果；证据评级为“部分覆盖”。当前托管 Worker 到 iFinD 的 8643 端口超时，因此公网环境降级为 2026-10-13 经本机真实调用核验的快照，并在结果中标出该限制；快照超过 7 天后自动视为不可用。
- **来源与时效**：保存上游时间戳和扶摇 request_id；证据详情显示本次取数时间。页面不把过期、缺页、缺失的维度当作正常数据。相同指数和维度的取数在服务进程内缓存 2 分钟，降低免费额度消耗。

## 已知边界与未做事项

目前未接入全市场历史宽度、资金流向和官方政策原文，因此不做严格的历史同状态匹配或事件归因。资讯检索片段没有稳定的全文授权，只提供原文链接供用户复核。大模型归纳依赖独立密钥；没有配置时不会运行。全市场分页的公共访问可能消耗较多额度，生产长期运行需要持久缓存与平台级限流。本项目不处理个人持仓或用户画像。
